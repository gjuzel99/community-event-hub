# Community Event Hub Roadmap

Community Event Hub will be built publicly through a series of live episodes.

The goal is not only to build an event-management application, but also to demonstrate how to make practical and maintainable engineering decisions when working with Microsoft Power Platform and Dataverse.

The roadmap will evolve as the project grows.

## Episode 1 — Project Foundation

**How to Start a Maintainable Power Platform Project**

Before creating tables or writing code, we will define the foundation of the project.

Topics:

- project vision and goals;
- project scope and non-goals;
- initial architecture;
- maintainable Power Platform engineering principles;
- initial repository structure;
- roadmap for the next episodes.

**Result:** A documented project foundation that explains what Community Event Hub is, what it is not, and how we plan to build it.

---

## Episode 2 — Dataverse Foundation

**Designing a Maintainable Dataverse Foundation**

We will create the Power Platform solution and start designing the Dataverse foundation for Community Event Hub.

Topics:

- creating and configuring the Dataverse solution;
- solution publisher and naming strategy;
- scalable Git repository structure;
- understanding standard Dataverse tables before creating custom ones;
- using Account and Contact where they fit the domain;
- understanding Dataverse activities such as Appointments, Emails and Tasks;
- deciding when a custom table is actually needed;
- designing the initial Community Event Hub data model.

**Result:** The first real Dataverse foundation and a documented data model that can grow with the project.

---

## Episode 3 — Business Logic Architecture

**Plugin, JavaScript or Power Automate?**

Before implementing business logic, we will decide where different types of logic should live.

We will use real Community Event Hub requirements to compare the available Power Platform options.

Topics:

- Dataverse configuration and platform features;
- Business Rules;
- JavaScript and TypeScript for client-side behaviour;
- Dataverse plugins for server-side business logic;
- Power Automate for asynchronous processes and notifications;
- avoiding duplicated business logic;
- deciding which technology fits each requirement;
- documenting the project's business-logic strategy.

**Result:** A practical decision guide for choosing where Community Event Hub business logic should be implemented.

---

## More Episodes Will Follow

These are only the first steps of Community Event Hub.

Future episodes will continue building the project and may cover topics such as:

- building the model-driven application;
- Dataverse plugins;
- maintainable TypeScript and JavaScript;
- Power Automate;
- security;
- testing;
- ALM and deployment;
- PCF components;
- integrations with platforms such as Sessionize and run.events;
- and other challenges that appear while building the project.

The roadmap is intentionally flexible.

New episodes will be added as the project develops and as new architectural and technical decisions need to be made.
